# 关于

**观照**（guān zhào）是 Dhammadassī 的数字花园。

这里记录的是一个人用 AI 与系统思维面对真实世界、用佛法与长期主义校正判断的过程。

内容从个人 Obsidian 知识库中精选发布，涵盖佛法修学、AI 实践、以及两者交叉处的思考。

## 关于名字

「观照」是佛教修行中的核心动作——如实观察身心现象，不加入主观评判。这也是这个站点想要保持的姿态：安静地看，如实地写。

## 关于技术

这个站点使用 [Obsidian](https://obsidian.md) 作为编辑器，[Quartz](https://quartz.jzhao.xyz) 作为静态站点生成器，托管在 GitHub 上。从知识库到公开站点的同步通过自定义脚本完成。
