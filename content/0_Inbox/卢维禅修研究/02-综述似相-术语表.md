# 02-综述似相 术语表

> 作者：岩石行者 | 术语数：16

## 核心术语

| 术语   | 巴利语            | 原文上下文要点                                                                       |
| ------ | ----------------- | ------------------------------------------------------------------------------------ |
| 似相   | Paṭibhāga-nimitta | 非五感官感知，由心在意门造作。依动摇取相而产生，是宁静停止相。不动摇不变化非欲求而得 |
| 取相   | Uggaha-nimitta    | 观呼吸中呼吸来回进出的动摇相，如秋千摆动。似相依此建立                               |
| 安止定 | Appanā-samādhi    | 清净道论说心依靠似相才能获得安止定                                                   |
| 轻安   | Passaddhi         | 宁静相让心轻安、喜乐                                                                 |
| 初禅   | Paṭhamaṃ jhānaṃ   | 闭眼所见光亮非似相，初禅以下包括初禅的禅定境界                                       |

## 禅支

| 术语   | 巴利语         | 原文上下文要点                                   |
| ------ | -------------- | ------------------------------------------------ |
| 五禅支 | Pañca-jhānaṅga | 寻、伺、喜、乐、一心。似相稳定后依靠似相自发产生 |
| 寻     | Vitakka        | 依靠似相不断自发产生。心主动投向目标             |
| 伺     | Vicāra         | 依靠似相不断自发产生。心在目标上细密摩擦         |
| 喜     | Pīti           | 禅支。宁静相让心轻安喜乐                         |
| 乐     | Sukha          | 禅支。宁静相让心轻安喜乐                         |
| 一心   | Ekaggatā       | 禅支。心与目标合一                               |

## 界与心法

| 术语     | 巴利语            | 原文上下文要点                             |
| -------- | ----------------- | ------------------------------------------ |
| 意门     | Manodvāra         | 似相由心在意门造作出来，不依赖欲界感官     |
| 欲界     | Kāmāvacara        | 似相不依赖欲界感官而存在，故具备不动摇特质 |
| 色界净色 | Rūpāvacara-pasāda | 心摆脱五感官约束后获得色界净色产生光明     |
| 神通力   | Abhiññā           | 似相光明展现到眼根转化而来，非内在视觉效果 |
