# 观照测试笔记

这是数字花园的第一篇测试笔记。如果你能在 `guanzhang.dhammaai.com` 上看到这篇内容，说明发布管道已经打通。

## 这是什么

这个数字花园使用以下技术栈：

- **后台**：Obsidian（本地 Markdown 编辑）
- **同步**：Python 脚本扫描 `publish: true` 标记的笔记
- **前端**：Quartz v5（静态站点生成器）
- **托管**：Cloudflare Pages
- **域名**：`guanzhang.dhammaai.com`

## 工作流程

1. 在 Obsidian 里写笔记
2. 在 frontmatter 里加 `publish: true`
3. 运行 `python3 sync-from-vault.py`
4. 脚本自动复制笔记 + 图片 + 嵌入到 Quartz repo
5. Git push 触发 Cloudflare Pages 自动部署
